# Four-Dimensional 核心玩法概述

> 本文档描述当前项目已实现的单局核心循环与战斗规则，供设计、测试和对外介绍时快速参考。数值、卡牌和奖励池会随平衡调整而变化；规则以实际游戏与代码为准。

## 一句话定位

《Four-Dimensional》是一款以四人小队为核心的回合制卡牌构筑 Roguelite。玩家在节点地图上规划路线，通过共享牌堆战斗、队伍站位与多层成长资源，击败区域首领并继续向下一片区域推进。

## 单局循环

```text
开局增益选择
  → 在节点地图选择可达路线
  → 处理战斗／事件／商店等节点
  → 获得并调整卡牌、天赋、装备、遗物与消耗品
  → 应对更强的精英与首领
  → 进入下一片区域或在全员濒死时结束本局
```

一局游戏的重点不只是赢下当场战斗，还包括为后续节点保留生命、规划电力币支出，并让四名角色的卡牌和被动形成稳定联动。

## 地图与路线决策

地图由相连的节点构成。玩家只能前往当前节点后续已解锁的路线，因此需要在即时收益与风险之间取舍。

| 节点 | 核心作用 |
| --- | --- |
| 普通战斗 | 获得常规战斗奖励，并继续推进地图。 |
| 精英战斗 | 面对更高压力的敌方编队；胜利后可获得遗物奖励。 |
| 首领 | 区域末端的关键战斗；击败后推进区域，并触发首领遗物选择。 |
| 事件 | 在多个选项之间取舍，结果可能涉及生命、电力币、卡牌、天赋或遗物。 |
| 商店 | 消耗电力币购买成长资源，或删除不需要的卡牌。 |
| 休息 | 恢复队伍生命，为高风险节点做准备。 |
| 宝箱 | 获取额外资源与成长机会。 |

电力币是商店的主要货币；队伍生命则会跨战斗保留。路线选择因此同时决定了本局的经济、构筑节奏与生存压力。

## 战斗核心

### 阵营阶段与行动顺序

战斗在我方阵营阶段与敌方阵营阶段之间交替进行。角色和敌人的站位会影响同阵营中的行动顺序、相对目标以及部分技能效果；技能描述中的“前一位”和“后一位”指编队中的相邻队友，队伍首尾相连计算。

玩家需要在战前界面调整编队、查看角色卡组和天赋。进入战斗后，应结合敌人的意图、当前站位与下一回合风险决定出牌和结束回合的时机。

### 共享手牌与牌堆

四名角色的技能会组成一个**队伍共享牌堆**：

- 我方阵营阶段开始时，从共享抽牌堆抽取手牌；存活角色越多，基础抽牌数越高。
- 任意角色所属的卡都可能出现在同一手牌中，因此一回合的决策应从全队资源而非单个角色出发。
- 打出的卡牌，以及回合结束时未保留的手牌，会进入共享弃牌堆。
- 抽牌堆耗尽后，弃牌堆会洗回抽牌堆继续使用；部分卡牌或状态会在使用后消耗，不再进入循环。

卡牌包含攻击、生存、特殊、能力与状态等类型。攻击和支援效果可能自动选取目标，也可能要求玩家指定友方目标；悬停卡牌可查看效果、关键词、目标高亮与数值预览。

### 共享能量与回合结束

我方使用的是**队伍共享能量**。每个我方阵营阶段开始时会获得能量，所有角色打出的卡牌共同消耗这份资源；某些卡牌、状态、装备和遗物可以额外产能、储能或改变费用。

当手牌与能量无法形成有效解法时，玩家可以结束回合。结束后会结算手牌弃置、回合末状态和持续效果，然后由敌方按其行动逻辑完成一个阵营阶段。大多数未储存的能量会在我方阶段结束时清空。

### 伤害、生存与状态

- 伤害会优先扣除格挡，再扣除生命。
- 生命降至 0 的角色进入濒死，无法进行常规行动；只有带有“复生”效果的卡牌或状态能使其重新参战。
- 我方全员濒死即告负；敌方全员濒死即获胜。
- Buff、Debuff、召唤物与被动可在行动开始、出牌、受击、行动结束或阵营阶段结算时触发，构成连锁效果。

敌方会展示后续意图。有效的防守并不只是回复生命，也包括利用格挡、控制、减益、目标规则和击杀顺序降低下一轮威胁。

## 构筑与成长

玩家围绕四名固定队员——Echo、Kasiya、Mariya 与 Nightingale——建立整队构筑。每名角色拥有独立的技能池、被动与天赋，但其技能会与队友卡牌一同进入共享牌堆，因此卡牌的费用、出牌条件、目标和触发频率都要从全队角度衡量。

| 成长系统 | 对玩法的影响 |
| --- | --- |
| 技能卡 | 战斗奖励、商店与事件可新增、复制、变化或移除卡牌，直接改变共享牌堆的稳定性与上限。 |
| 属性与天赋 | 提升力量、生存、生命上限或角色被动，强化明确的角色定位与分支选择。 |
| 装备 | 分配给角色，提供属性修正或战斗开始时的特殊效果。 |
| 遗物 | 通常在战斗开始、阵营开始、出牌或战斗结束等时机自动生效，提供长期规则改变。 |
| 消耗品 | 数量有限的主动资源，可在关键战斗中用于治疗、格挡、增益、伤害、抽牌或能量调度。 |

构筑时需要持续回答三个问题：

1. 共享牌堆能否稳定抽到当前队伍最需要的牌？
2. 共享能量是否足以支撑关键卡牌在同一阶段连续打出？
3. 编队、被动、遗物与装备是否在同一战术方向上互相放大？

## 一场战斗中的典型决策

1. 阅读敌方意图，判断本回合最需要处理的威胁。
2. 结合手牌、能量和角色站位，确定先手卡与关键目标。
3. 在输出、格挡、治疗、控制、抽牌和能量之间安排出牌顺序。
4. 判断是否保留资源应对敌方阶段，或提前结束回合止损。
5. 胜利后根据当前路线和牌堆短板选择奖励，而不是只选择单张数值最高的卡。
