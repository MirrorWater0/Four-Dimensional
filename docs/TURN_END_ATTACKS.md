# 回合结束攻击

玩家共享出牌阶段结束后，我方存活角色按 `PositionIndex` 升序依次普通攻击。默认每人1次，每次伤害无基础值：`BattlePower × 1`，保留角色伤害倍率、被动攻击加成及虚弱、易伤、格挡、嘲讽、隐身等攻击相关效果。每次重新选敌，击杀后后续攻击可转向其他存活敌人。全灭或攻击者死亡时停止对应攻击。敌方仍使用现有意图行动。

结算顺序为：结束出牌 → 全队普通攻击 → 清除临时次数 → 手牌回合结束效果与弃牌 → 回合结束 Buff → 敌方行动。普通攻击不花费能量，不算打出卡牌，不触发出牌次数或回响复制。

状态栏金色剑图标为常驻攻击次数（初始1，降至0仍显示）；青色剑骰图标为临时攻击次数（默认0，不显示；正数时显示；本回合攻击结算后清除）。常驻指本场战斗，不跨战斗保存。两类次数均可增减，下限0。队列开始时冻结顺序和次数，避免攻击触发无限延长队列。

基础攻击牌 `BasicAttack` 保留编号、名称、卡图及初始牌位置，改为0费特殊牌，获得1次临时攻击。每名角色初始卡组包含1张基础攻击、1张基础防御、1张护卫及1张角色基础特殊。其他玩家／无色攻击牌取消工厂注册，奖励、商店、随机生成卡池随之排除；旧存档中的对应编号保留，战斗牌堆构建会跳过未注册牌。敌方攻击技能继续注册。

南丁格尔原有利刃生成同步改为临时次数：被动回合开始时自己+1；刀刃之舞为所选友方+3；隐刃守势为每位隐身角色+1。

基础特殊、侵袭原有下一位队友攻击连携改为给予下一位队友1次临时攻击，避免连携抽取已注销的攻击牌。

技能通过 Step 修改次数，并自动生成说明、Buff 提示和预览：

```csharp
ModifyAttackCountStep(1) // 自己本场战斗每回合多攻击1次
ModifyAttackCountStep(1, temporary: true) // 自己仅本回合多攻击1次
ModifyAttackCountStep(-1) // 自己常驻次数减少1，下限0
ModifyAttackCountStep(2, temporary: true, target: TargetReference.All)
ModifyAttackCountStep(skill => skill.OwnerCharater.BattlePower, temporary: true)
```

默认目标为自己；支持现有友方目标（包含手动友方选择）。也可使用 `ApplyBuffFriendly` 添加 `AttackCount`／`TemporaryAttackCount`，统一路由至次数修改。

回归场景：`tools/TurnEndAttackRegression.tscn`。要求输出明确 PASS 后才视为运行验证成功。

## 回合结束伤害预览

我方出牌阶段，敌人意图上方显示「回合结束」、预计扣除的生命值及命中次数；格挡可吸收伤害时额外显示「格挡吸收」。伤害没有基础值。常驻与临时攻击次数、战斗力量或防御状态变化后，预览在0.1秒内刷新；开始实际结束回合结算时立即隐藏。面板沿用现有伤害预览资源，位置可通过 Battle 的 `TurnEndAttackPreviewOffset` 在编辑器调整（默认 Y=-450）；按面板实际高度自动避让意图与血条，保留24单位间距，显示时保持原始尺寸以避免放大动画造成短暂重叠。

预览使用独立的生命、格挡和 Buff 层数副本，按站位逐击模拟虚弱、神性、易伤、一次伤害免疫、嘲讽、隐身、反伤、自适应护甲和重生；模拟击杀后重新选敌，反伤致死后停止该角色后续攻击。不会触发动画、回调、真实伤害记录或消耗实际临时次数。

范围为回合结束的普通攻击，不包含后续手牌状态伤害及回合结束 Buff。存在影子形态、圣域或自定义死亡回调时标记「估算」，其连锁效果未模拟。极端攻击次数最多模拟4096击，并明确显示「部分预览」，避免 UI 卡死。
