# 伤害免疫护盾特效

- `DamageImmune` 层数大于 0 时，玩家角色和敌人身边会有三片淡青绿色弧形护盾绕身旋转。护盾片之间留有间隙，带倒角发光边缘和淡六边形纹路。
- 参考 `CharacterShadow` 分成 `Back`、`Front` 两个绘制层：后半圈在立绘后，前半圈在立绘前。两层使用相同角度和时钟，护盾片经过角色两侧时连续转入另一层。
- 抵消伤害时，护盾片亮起并显示从攻击者方向扩散的波纹。最后一层被消耗后，先保留命中反馈，再淡出护盾。
- 护盾跟随 `Hoverframe` 的位置和尺寸，不跟随立绘的受击缩放。濒死时立即隐藏，角色节点释放时一同清理。
- 特效只提示状态，不改变伤害计算、免疫层数或格挡规则。

## 调整外观

打开 `res://battle/Effect/DamageImmuneShieldVfx.tscn`，可以直接在 2D 编辑器看到静态护盾片和前后层结构。根节点的 `RotationSpeed` 控制旋转方向和速度，默认每秒 0.85 弧度。

`Back`、`Front` 材质中的 `shield_color`、`rim_color` 控制配色，`panel_arc` 控制每片的弧长，`panel_height` 控制护盾片高度占角色框的比例；调整这些外观参数时，两层保持一致。`presence` 控制展开程度，`impact_age` 为 0 到 0.55 秒的受击阶段，`impact_origin` 控制冲击起点。`depth_layer` 分别固定为 -1 和 1。

战斗中由 `Character.DamageImmuneShield.cs` 根据 Buff 状态自动管理，同一角色复用一个节点，隐藏后停止逐帧更新。每个实例拥有独立材质，受击闪光不会串到其他角色。
