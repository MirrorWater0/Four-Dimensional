# 商店界面

`Shop/SpaceStationShop.tscn` 使用 1920×1080 设计画布。商店内容范围为 x368–1760、y112–1016，避开左侧队伍、遗物和道具栏，以及顶部资源栏、右下角战术入口。标题与离开按钮单独占一行，正文从 y216 开始，底部只显示购买结果或错误反馈。

正文分成技能与补给两栏，以留白和一条细分隔线区分。技能卡和价格在同一个网格单元内，卡面与价格之间留 14 像素；技能区独立纵向滚动，列数按可用宽度调整，最多五列。默认卡牌缩放为 0.70，保留悬停提示，并收小悬停放大幅度，避免压住相邻卡面或价格。

右栏宽 320 像素，依次显示遗物、道具和服务。遗物与道具各自使用三列网格，商品售出后保留原有位置。清理服务使用 `Shop/CardRemovalOffer.tscn` 中的简洁文字操作行，价格靠右，悬停时显示底线；详细效果保留在提示中。

主要布局、留白、字体、滚动条和装饰定义在场景与 `Shop/ShopTheme.tres` 中；脚本负责填充商品、按宽度调整列数及原有购买、扣费、提示和动画流程。背景连线已降低亮度，移除重复标题、说明和外框装饰。
