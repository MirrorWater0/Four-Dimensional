# 事件界面

事件布局位于 `Event/EventInterface.tscn`，以 1920×1080 设计画布为基准。正文区域起于 x416，避开左侧道具、角色状态及遗物栏。左栏显示事件类别、标题和可滚动正文；右栏用三条行动选项展示抉择，没有整体外框或空白图片区。全屏背景遮罩不透明度为 58%，地图可透过背景显示；目标选择与结果面板也采用半透明底板。

事件、开局增益、休息、宝箱与区域遗物奖励共用布局，根据事件类型显示简短类别。删除重复副标题和虚构的英文区域编号；事件正文、选项条件、奖励与消耗规则保持原有数据。

`Event/EventTheme.tres` 负责冷灰蓝文字与细滚动条。操作按钮统一使用 `UI/ActionButtonTheme.tres` 与 `UI/ActionButtonFeedback.tscn`，匹配开始界面“统计”的文字按钮：文字靠左并略向内缩进，不带箭头或常驻底线。常态、悬停、按下和焦点均无背景填充；悬停或聚焦时底部细线延展并淡入，移开后收回淡出，禁用时只显示暗色文字。划线在场景内定义，编辑器可见，脚本只负责反馈动效。动态创建的卡牌选择确认/取消按钮通过 `ActionButtonFeedback.ApplyTo` 复用相同场景。

同类操作按钮同步用于角色选择、菜单返回/操作、百科数值操作、地图探索与世界线切换、商店离开、奖励跳过/完成、结算返回、统计返回、战斗牌堆及教程操作。选项仍有依次入场与点击反馈，鼠标悬停或键盘聚焦可查看原有效果提示。

角色目标选择位于 `Event/TargetSelectOverlay.tscn`，在事件内容范围内居中，复用事件主题。结果提示也在事件内容范围内居中，长结果可滚动；滚轮不会触发关闭，左键或触屏点击继续。

`Map/Map.WorldLine.cs` 在事件等阻塞界面打开时隐藏世界线面板和道路推进按钮，关闭后恢复。地图查看模式显示世界线面板，并隐藏道路推进按钮。

本次仅做代码、场景引用及差异检查，未构建、启动 Godot 或运行测试。实际显示与交互仍待运行确认。
