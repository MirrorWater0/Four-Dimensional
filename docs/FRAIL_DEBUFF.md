# 脆弱

`Buff.BuffName.Frail` 是负面状态，可被减益免疫抵消。持续期间，每次获得的格挡变为原来的 75%，向下取整。例如 10 点变为 7 点，1 点变为 0 点。多个层数只延长持续时间，不叠加减幅；己方阵营回合结束时减少 1 层，降至 0 时移除。

减幅在 `Character.UpdateBlockCore` 的统一入口按接收者结算，适用于技能、被动、自动护盾以及灯塔分享等来源，不扣除已有格挡。卡牌目标效果预览在合并前对每次获取单独取整；行动结算预览使用模拟状态中的脆弱层数，避免重复减幅。已有的负面状态层数翻倍效果也支持脆弱。

## 设计目标与时机

脆弱用于在战斗中后段给已经启动、格挡产出过高的玩家重新施加防御压力。配置时先检查整个敌人阵容的后续伤害，优先给没有易伤或减生存能力的敌人；脆弱意图首次出现在第 3 至第 5 轮，不加入随机意图池，也不随机从周期后段开局。

单体脆弱从当前可选敌对角色中随机选择 1 人，使用 `HostileTargetReference.RandomPreview`：在意图显示时确定并缓存目标，预览、悬停和实际执行共用该目标，下次此意图重新随机。目标失效时沿用现有目标重选规则。单体施加者必须有后续固定 AOE 或同阵容队友，能利用随机角色的格挡削弱。

设完整意图周期长度为 C，每周期施加一次：

- 单体层数为 2C。按三人队伍估算，每周期提供 2C 个角色回合的减益时长，平均分摊对应约 2/3 的覆盖预算。实际覆盖受随机重复、已有层数、免疫和阵营行动频率影响，不保证每个角色在每个周期恰好覆盖 2/3。
- 全阵层数为最接近 2C/3 的整数：4 步周期用 3 层，5 步用 3 层，6 步用 4 层。全阵不使用 2C 层，避免常驻。
- 每个普通阵容只启用 1 名脆弱施加者。`EnemyRegedit.CanApplyFrail` 在编队生成时确定；同种敌人不会因人数增加把覆盖预算成倍叠加，已有易伤或减生存的同伴也不额外补脆弱。施加者死亡后不自动把能力转移给其他敌人。

## 阵容分配

普通编队按 `NormalBattleEncounter.FrailCarrierPriority` 选 1 名施加者。BlackHawk、蚀髓刃虫、空壳壁卫优先，其次 RedHusk、Armon、虚空侍从，再次 Evil，最后才是已有减生存的 AlienBody。同优先级按站位选择。

| 遭遇表 | 覆盖数 / 总数 | 阵容与实际施加者 |
| --- | --- | --- |
| 第一区域普通阵容 | 6 / 8 | 单 Evil：Evil；双 AlienBody：1 只 AlienBody；Evil + FearWorm：Evil；双 Evil：1 只 Evil；三 AlienBody：1 只 AlienBody；BlackHawk + AlienBody：BlackHawk |
| 第二区域普通阵容 | 5 / 6 | 双 RedHusk：1 只 RedHusk；三 Armon：1 只 Armon；蚀髓刃虫 + Evil：蚀髓刃虫；空壳壁卫 + 虚空侍从：空壳壁卫；虚空侍从 + 虚空转子 + AlienBody：虚空侍从 |
| 精英阵容 | 1 / 4 | 愤怒；Arrogance、嫉妒、恐惧保留现有易伤、减生存等防御压制，不增加脆弱 |
| Boss 阵容 | 3 / 3 | War、Havoc、Death |
| 合计 | 15 / 21 | 约 71.4% |

优先配置无易伤、无减生存的施加者，可覆盖 12 种阵容；低优先级的双异体、三异体与愤怒补足另外 3 种。21 种阵容无法恰好覆盖 70%，15 种是最接近的整数数量；每局实际遭遇比例还受区域、队列与随机 Boss 选择影响。
